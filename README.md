# 🎓 موقع الجامعة | University Website Template

أول مشروع في مسيرتي البرمجية نحو احتراف تطوير الويب! 🚀

موقع ويب تفاعلي ومتجاوب لجامعة، تم تصميمه وبناؤه من الصفر باستخدام تقنيات الويب الأساسية (**HTML5** و **CSS3**)، مع التركيز على تجربة المستخدم (UX) والواجهات العصرية.

---

## 🌟 مميزات المشروع (Features)

- 🎨 **تصميم عصري وجذاب:** واجهة مستخدم أنيقة ومريحة للعين.
- 📱 **متجاوب بالكامل (Responsive Design):** يعمل بمرونة على جميع الشاشات (كمبيوتر، تابلت، وهواتف ذكية).
- 🧭 **تنقل سلس:** شريط تنقل (Navbar) منظم لسهولة الوصول لجميع صفحات الموقع.
- ⚡ **أداء سريع:** كود نظيف وهيكلية خفيفة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **HTML5:** لبناء هيكلية الصفحات والعناصر الأساسية.
- **CSS3:** للتنسيق، الألوان، الخطوط، واستخدام Flexbox / Grid للتجاوب.
